# Memory Model

Memory is one of the most sensitive parts of the project. It can make the companion feel deep and trustworthy, or invasive and presumptuous.

The core principle is:

**Memory should be earned, not hoarded.**

## 1. Stable memory

Things that are part of the enduring map.

Examples:

- meaningful places
- recurring people or contexts that matter
- values explicitly expressed
- boundaries and don’ts
- preferred outreach style
- sleep and protected-time patterns
- themes that stay true over time

This kind of memory should persist.

## 2. Evolving memory

Things that may be true for a phase, but not forever.

Examples:

- current life-phase themes
- current tensions or questions
- places that recently gained meaning
- rhythms that have shifted
- whether this season feels open, heavy, uncertain, or alive

This should persist, but be revisable and reweighted over time.

## 3. Short-lived memory

Things that matter for context, but should naturally fade.

Examples:

- this week felt heavy
- recent emotionally meaningful visits
- recent silence or restlessness
- recent outreach that felt welcome or unwelcome
- recent patterns in going out, staying in, or pausing

This should decay unless reinforced.

## 4. Sensitive memory

Things it should only keep if explicitly confirmed.

Examples:

- deep personal wounds
- private family details
- relationship pain
- things mentioned once in a vulnerable moment
- highly charged interpretations about what something means

The system should not overcommit fragile things into its permanent model of you just because they came up once.

## What should persist

- boundaries
- values
- meaningful places that repeat
- stable relational anchors
- preferred style of contact
- confirmed identity-level truths

## What should fade

- temporary moods
- one-off interpretations
- recent weekly patterns
- contextual guesses
- moments that were never reinforced

## What should require confirmation

- deep emotional conclusions
- identity claims
- charged relational interpretations
- anything that could shape future outreach in a heavy way

## Example rules

- "Parents’ place matters to you" can become stable memory if reinforced repeatedly
- "This week felt uncertain" should be short-lived unless it becomes part of a larger phase
- "You are grieving X" should not become long-term truth unless explicitly confirmed or strongly revisited
- "Do not call me when I’m at this place" should become stable memory immediately

## Practical memory behavior

### Remember easily

- boundaries
- repeated place meaning
- repeated life rhythm
- repeated welcome or unwelcome outreach patterns

### Remember cautiously

- emotional interpretations
- phase assumptions
- inferred meaning of unusual pauses
- relational conclusions

### Forget gracefully

- stale weekly context
- unsupported guesses
- one-off anomalies
- low-confidence observations
